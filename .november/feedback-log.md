# Feedback Log — commudle-ng

Corrections given directly to agents operating in `commudle-ng` — not
corrections given to root-level agents, which belong in
`commudle-hq/.november/feedback-log.md` instead.

Logged automatically, always, no confirmation needed. This is a record, not
a proposal — logging an entry here never modifies any rule or agent file on
its own. If the same correction appears a third time, the agent that logged
it will flag the pattern and ask whether to fold it into the relevant rule
or persona file permanently — see Self-Update Policy in `AGENTS.md`.

Newest entries at the top.
